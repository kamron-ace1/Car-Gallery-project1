## �📋 Loyiha haqida

**BMW Heritage Gallery** – bu BMW tarixidagi eng mashhur va noyob avtomobil modellarini namoyish etadigan interaktiv web-galereya. Saytda 7 ta eksklyuziv model, ularning to'liq texnik xususiyatlari, qiziqarli tarixiy ma'lumotlar va zamonaviy interfeys mavjud.

### 🎯 Maqsad

Bu loyiha zamonaviy web-texnologiyalarni (HTML5, CSS3, JavaScript) o'zlashtirish va amaliy qo'llashni ko'rsatadi.

## 🚀 O'rnatish va Ishga tushirish

### 1️⃣ **Bosqich: Repository-ni klon qiling**

```bash
git clone https://github.com/kamron-ace1/Car-Gallery-project1.git
cd Car-Gallery-project1/Car-Gallery-project1
```

### 2️⃣ **Bosqich: Fayl ochish**

Web-saytni ochish uchun `index.html` faylni brauzeringizda oching:

```bash
# Windows-da
start index.html

# macOS-da
open index.html

# Linux-da
xdg-open index.html
```

Yoki istalgan web-serverni ishga tushiring:

```bash
# Python 3
python -m http.server 8000

# Node.js (http-server)
npm install -g http-server
http-server
```

Keyin `http://localhost:8000` ga o'ting.
